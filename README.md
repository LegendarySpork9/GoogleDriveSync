# GoogleDriveSync [![Commit Status](https://github.com/LegendarySpork9/GoogleDriveSync/actions/workflows/Commit.yml/badge.svg?event=push)](https://github.com/LegendarySpork9/GoogleDriveSync/actions/workflows/Commit.yml) [![PR Status](https://github.com/LegendarySpork9/GoogleDriveSync/actions/workflows/Pull%20Request.yml/badge.svg)](https://github.com/LegendarySpork9/GoogleDriveSync/actions/workflows/Pull%20Request.yml)

Desktop application for bidirectional file synchronisation between local directories and Google Drive. Detects content changes, path changes, and new files with support for manual or automatic sync on a timer.

## Tech Stack

| Technology | Version |
|------------|---------|
| .NET Framework | 4.7.2 |
| Language | C# |
| UI Framework | Windows Forms |
| Cloud Storage | Google Drive API v3 |

## Status

Active development
